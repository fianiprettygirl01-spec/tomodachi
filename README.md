# 絆 (Kizuna) • Website Ucapan Terima Kasih Sahabat

Website apresiasi dan penyemangat untuk sahabat laki-laki tercinta, dengan pesan utama:
> **おつかれさまでした (Otsukaresama deshita)** — *Terima kasih sudah menjadi kuat dan pantang menyerah, bro!*

---

## 🌟 Fitur Utama
1. **Palet Warna & Estetika**:
   - Diadaptasi dari tema `Tema Warna.jpg` dengan perpaduan langit biru cerah, kaca frosted modern (*glassmorphism*), dan aksen hangat yang seimbang & maskulin untuk sahabat cowok.
2. **Visual Showcase**:
   - Latar langit anime cerah dari `sky.jpg`.
   - Maskot humoris & penuh kasih dari meme kucing pembawa buket bunga `cat flower.jpg`.
3. **Fitur Kejutan Spesial (*Surprise Appreciation*)**:
   - Menampilkan tulisan besar **「ありがとうございます」 (Arigatou Gozaimasu)**.
   - Efek kembang api/konfeti partikel emas, biru & kelopak bunga.
   - Suara kuis & *sparkle fanfare* sintetis instan (Web Audio API).
   - Tombol reaksi interaktif: *👊 Tos Bro, 🔥 Membara, 🍻 Gass Nongkrong, ❤️ Respect*.
4. **Kapsul Semangat (Omikuji 3D Flip Cards)**:
   - 6 Kartu booster motivasi & mood yang bisa dibalik secara 3D (Marah, Sedih, Senang, Kecewa, Sakit, Malas).
5. **Kucing Interaktif**:
   - Klik kucing pembawa bunga untuk memunculkan pesan-pesan kocak dan menyemangati secara bergantian beserta animasi lompat (*bounce*).
6. **Tos Semangat (Bro Fist Counter)**:
   - Hitungan tos virtual yang tersimpan otomatis di browser.
7. **Musik Pengiring Lofi / Suara**:
   - Toggle audio generator bawaan tanpa perlu unduh file MP3 eksternal.

## 🚀 Cara Menjalankan Secara Lokal
Buka folder ini di browser atau jalankan server lokal sederhana:

### Opsi 1: Menggunakan Node.js
```bash
npx serve .
```
atau langsung klik ganda file `index.html`.

## 🌐 Cara Hosting di Vercel (Gratis & Sangat Cepat)

### Cara 1: Menggunakan Vercel CLI (Paling Cepat)
1. Buka Terminal / PowerShell di folder ini (`D:\Fun\Gil chan`).
2. Jalankan:
   ```bash
   npx vercel
   ```
3. Ikuti petunjuk di layar (tekan Enter untuk opsi default).
4. Website langsung aktif dengan domain `.vercel.app`!

### Cara 2: Melalui Dashboard Vercel (Drag & Drop / GitHub)
1. Masuk ke [vercel.com](https://vercel.com).
2. Buat repositori baru di GitHub dan unggah folder ini, atau gunakan fitur Import Project.
3. Karena project ini berupa Static Web (HTML, CSS, JS murni), Vercel akan otomatis mendeteksi dan langsung mendeploy tanpa perlu setting tambahan.
4. Bagikan link website ke sahabatmu! 🎁
